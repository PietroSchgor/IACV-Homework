# Image Analysis and Computer Vision - Homework

This repository contains the code, data, and report for an Image Analysis and Computer Vision project focused on the geometric analysis and 3D reconstruction of the *San Maurizio al Monastero Maggiore* church from a single image.

## Project Overview

The main objective of the project is to perform a stratified 3D reconstruction from a single perspective view by exploiting architectural symmetries, vanishing points, and projective geometry constraints.

### Pipeline
1. **Feature Extraction & Vanishing Geometry:** 
   Manual extraction of lines to compute the vanishing points for the 3 orthogonal directions ($V_x, V_y, V_z$) and the vanishing line of the horizontal plane ($\ell'_\infty$).
2. **Rectification:**
   - *Affine Rectification:* Applying an affine mapping to send the vanishing line to infinity, restoring parallelism.
   - *Metric Rectification:* Restoring the circularity of the vault arches. Midpoints of the arches are found using harmonic conjugates (cross-ratio). A conic is then fitted and circularized to find the metric rectifying homography.
3. **Camera Calibration:** 
   Estimation of the Image of the Absolute Conic (IAC) $\omega$ by enforcing Zhang's constraints (from the rectifying homography) and the pole-polar relationship (from vanishing points). This allows recovering the camera intrinsic matrix $K$.
4. **3D Reconstruction:** 
   Triangulation of points belonging to a diagonal arch. By exploiting the known distance between two parallel diagonal arches and the Law of Sines, we calculate the depth of the points.
5. **Cylinder Axis Localization:** 
   Localization of the 3D position of the cylindrical vault's central axis by intersecting the ray corresponding to the image's circular cross-section center with a reference 3D plane.

## Repository Structure

### Scripts (MATLAB)
- `main.m`: The main executable script running the entire pipeline described above.
- `extract_lines.m`, `extracted_midpoint.m`, `seleziona_archi_paralleli.m`, `seleziona_midpoints.m`: Scripts dedicated to the manual, reproducible extraction of geometric features from the image (lines, midpoints, arches).
- `midpoint_crossratio.m`: Calculates midpoints based on the projective invariant of the cross-ratio.
- `AtoG.m`: Helper functions for geometric transformations or solving specific systems.

### Folders and Assets
- **`images/`**: Contains the output plots generated by the code, including the rectified planes, detected features, and 3D reconstructions.
- **`mat/`**: Stores the manually extracted features and variables as `.mat` files (`dati_linee.mat`, `extracted_features.mat`, etc.) to prevent having to click through the image manually at every execution.
- **`report latex/`**: Contains the source `.tex` files, bibliography, and figures used to compile the final project report.
- **`San Maurizio.jpg`**: The input image of the church.
- **`Report_10710527.pdf`**: The detailed final written report explaining the mathematical background and results.
- **`results.txt`**: A plain text log of the mathematical outputs (matrices, coordinates) produced during execution.
